= Т02. Городской общественный транспорт

Практическая работа № 6. Документация как код.

== Назначение комплекта

В репозитории представлена документация по взаимодействию компонентов информационной системы городского общественного транспорта.

В основу комплекта положены требования практической работы № 2, модели TO-BE практической работы № 3 и описание интеграций и интерфейсов практической работы № 4.

== Состав документации

* link:docs/requirements.adoc[Спецификация требований]
* link:docs/interface.adoc[Интеграции и интерфейсы]
* link:models/README.adoc[Целевая модель TO-BE]

== Структура репозитория

* `docs` — требования, интеграции и интерфейсы.
* `docs/images` — макеты рабочего места диспетчера UI-01.
* `models` — диаграммы BPMN, UML и ER модели TO-BE.

== Формат документации

Текстовые документы оформлены в формате AsciiDoc, диаграммы представлены в формате SVG, макеты интерфейса — в формате PNG.
