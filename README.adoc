= Т02. Городской общественный транспорт

Практическая работа № 6. Документация как код.

== Назначение комплекта

В репозитории представлена документация по взаимодействию компонентов информационной системы городского общественного транспорта.

В основу комплекта положены требования практики № 2, модель TO-BE практики № 3 и описание интерфейса из практики № 4.

== Границы рассматриваемого фрагмента

Рассматривается обмен сведениями между ядром учёта C-01 и адаптером согласованного пассажирского канала C-03 при изменении движения транспорта.

Справочная служба, остановочные табло и работа водителей остаются за границами рассматриваемого фрагмента.

== Структура репозитория

* `README.adoc` — описание комплекта.
* `docs/requirements.adoc` — спецификация требований.
* `docs/interface.adoc` — описание интерфейса IF-01.
* `models/` — материалы целевой модели.
* `build/` — результаты сборки.
* `verification.adoc` — результаты проверки документации.

== Порядок чтения

. Спецификация требований.
. Целевая модель.
. Описание интерфейса IF-01.
. Результаты проверки документации.

== Порядок сборки

Документы в формате AsciiDoc преобразуются в HTML с помощью Asciidoctor. Полученные файлы размещаются в каталоге `build/`.
